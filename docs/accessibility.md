# Accessibility quality

Playwright runs Axe against the unauthenticated login and authenticated product experiences. The raw evidence records rule ID, impact, help text, and affected targets. Critical and serious automated violations block the default gate.

Automated tooling detects only a subset of WCAG issues. A mature program also performs keyboard-only navigation, focus order/visibility, zoom/reflow, screen-reader journeys, colour/contrast review, cognitive/usability assessment, and testing with disabled users. Therefore a zero-Axe report must never be claimed as full WCAG conformance.
