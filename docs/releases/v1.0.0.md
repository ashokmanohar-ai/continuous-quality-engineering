# v1.0.0 — Continuous Quality Engineering Release System

This first stable portfolio release demonstrates an evidence-based release system that treats quality as a measurable property of CI/CD rather than a testing phase.

## Included evidence

- Fastify/TypeScript application with real SQLite persistence
- Vitest, Playwright API/integration/E2E, Pact and Axe assurance layers
- k6 performance profiles and security evidence from multiple scanners
- normalized evidence with explicit missing-report handling and hard gates
- transparent quality scoring, flaky-test governance and change-impact selection
- PR, nightly, security, performance and release workflows plus Docker
- a recruiter quick tour and five-minute local proof path

## Verification

```bash
npm ci
npx playwright install --with-deps chromium
npm run quality
npm run quality:aggregate
npm run quality:report
npm run quality:gate
```

## Scope and limitations

This is a deliberately small synthetic application wrapped in a mature quality system. Demonstration trend fixtures are labelled; they are not customer-production measurements.
